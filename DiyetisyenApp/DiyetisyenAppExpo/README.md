# 🎉 Diyetisyen Uygulaması - Expo Versiyonu

**Modern, hızlı ve kolay kullanımlı diyetisyen takip uygulaması!**

## ✨ Özellikler

- 👥 **Hasta Yönetimi** - Detaylı hasta takibi
- 🍎 **Yemek Listesi** - Besin değerleri ve tarifler
- 📅 **Randevu Sistemi** - Kolay randevu yönetimi  
- 💰 **Muhasebe** - Gelir/gider takibi
- 📊 **Dashboard** - Özet istatistikler

## 🚀 Hemen Test Edin! (30 Saniye)

### 1. Expo Go'yu İndirin
- **Android:** [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
- **iOS:** [App Store](https://apps.apple.com/app/expo-go/id982107779)

### 2. Başlatın
```bash
cd DiyetisyenAppExpo
npm install
npx expo start
```

### 3. QR Kodu Taratın
- Expo Go uygulamasını açın
- QR kodu taratın
- Uygulama yüklendi! 🎉

## 📦 APK Oluşturma

Detaylı rehber: [`EXPO_APK_REHBERI.md`](EXPO_APK_REHBERI.md)

### Hızlı Yol:
```bash
npm install -g eas-cli
eas login
eas build --platform android --profile preview
```

10-15 dakika sonra APK hazır! ⚡
